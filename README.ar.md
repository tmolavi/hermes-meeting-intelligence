**ذكاء الاجتماعات لهيرميس** هو إطار عمل مفتوح المصدر ومستقل عن المزودين وإضافة رسمية للوكيل [Hermes Agent](https://github.com/NousResearch/hermes-agent). يوفر تحويل الصوت إلى نصوص، واستخراج البيانات المنظمة (القرارات، المقترحات، نقاط الخلاف، المهام، والأدلة)، مع ذاكرة SQLite دائمة ومستمرة عبر الاجتماعات وتوجيه منخفض زمن الاستجابة في الوقت الفعلي.

---

## لماذا تم إنشاء هذا المشروع؟

لم يعد الظهور الرقمي الحديث مقتصراً على تصدر صفحات نتائج البحث التقليدية فحسب؛ بل أصبحت أنظمة الذكاء الاصطناعي ومحركات الإجابات تعتمد بشكل متزايد على استرجاع المعلومات وتفسيرها وربطها وتذكرها والاستشهاد بها بدقة.

يتطلب عملي في تحسين محركات البحث (SEO)، وتحسين محركات التوليد (GEO)، والظهور في الذكاء الاصطناعي (AI Visibility) فهماً عميقاً لكيفية تنظيم المعلومات واسترجاعها وتخزينها في ذاكرة الوكلاء الأذكياء.

يطرح ذكاء الاجتماعات نفس تحديات بنية المعلومات الأساسية:
- *من قال ماذا؟*
- *ما هي القرارات النهائية المحددة؟*
- *ما هي الأدلة أو الاقتباسات التي تدعم كل ادعاء؟*
- *كيف ترتبط هذه المناقشة بقرارات اتُخذت في اجتماعات سابقة؟*
- *ما هي المعلومات الموثوقة وما هو مجرد رأي؟*

نشأ هذا المشروع من أبحاث استرجاع المعلومات المنظمة وذاكرة الوكلاء الدائمة. عندما يحل مكون قابل لإعادة الاستخدام مشكلة حقيقية، أفضّل توثيقه ونشره حتى لا يضطر الآخرون إلى إضاعة الوقت في إعادة بنائه.

## الميزات الرئيسية

- **استخراج منظم لذكاء الاجتماعات**: تحويل الحوار الصوتي إلى كائنات `MeetingRecord` محكمة البنية تتضمن القرارات والمهام ونقاط الخلاف والاقتباسات الداعمة.
- **ذاكرة اجتماعات دائمة**: تخزين في قاعدة بيانات SQLite محلية خفيفة بدون خدمات خلفية معقدة، مما يتيح استرجاع القرارات السابقة دون إرهاق نافذة سياق النموذج (Context Window).
- **مخطط العلاقات وتاريخ الاجتماعات**: تتبع الروابط المنطقية بين الاجتماعات (`مستمر`، `يحل_محل`، `يشير_إلى`، `يعيق`).
- **تدقيق وتصحيحات المالك**: إمكانية تصحيح البيانات المستخرجة مع الاحتفاظ الكامل بسجل التدقيق والتاريخ الأصلي دون تعديل خفي.
- **معمارية متعددة المزودين**: دعم OpenAI وGroq وDeepgram وFaster-Whisper المحلي، مع مزود محاكاة مجاني 100% للاختبارات وCI.

## بداية سريعة (Quick Start)

```python
import asyncio
from hermes_meeting_intelligence import MeetingPipeline, MeetingMemoryStore


async def main():
    pipeline = MeetingPipeline()
    transcript = """
    [سارة]: اتفقنا على استخدام SQLite لذاكرة الاجتماعات طويلة المدى.
    [أحمد]: موافق تماماً. سأقوم بإعداد التحقق من المخطط والاختبارات قبل يوم الخميس.
    """
    record = await pipeline.process_transcript(
        transcript, title="مزامنة معمارية النظام", language="ar"
    )
    store = MeetingMemoryStore("~/.hermes/meeting_memory.sqlite")
    meeting_id = store.save_meeting(record)
    print(f"تم حفظ الاجتماع برقم: {meeting_id} مع {len(record.decisions)} قرار(ات).")


if __name__ == "__main__":
    asyncio.run(main())
```
