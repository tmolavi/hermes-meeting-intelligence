**هوش جلسات هرمس** یک چارچوب متن‌باز، مستقل از ارائه‌دهنده و پلاگین رسمی برای [Hermes Agent](https://github.com/NousResearch/hermes-agent) است. این پروژه تبدیل گفتار به متن ماژولار، استخراج داده‌های ساختاریافته (تصمیمات، پیشنهادات، اختلافات، وظایف و شواهد)، حافظه ماندگار SQLite میان‌جلسه‌ای و مسیریابی بلادرنگ حساس به تاخیر را فراهم می‌سازد.

---

## چرا این پروژه ایجاد شد؟

دیده‌شدن در وب و دنیای دیجیتال مدرن دیگر صرفاً به رتبه‌بندی صفحات وب محدود نمی‌شود. سیستم‌های مبتنی بر هوش مصنوعی و موتورهای پاسخ (Answer Engines) به طور فزاینده‌ای داده‌ها را بازیابی، تفسیر، متصل، به‌خاطر سپاری و استناد می‌کنند.

فعالیت‌های من در حوزه‌های سئو (SEO)، بهینه‌سازی موتورهای مولد (GEO) و دیده‌شدن در هوش مصنوعی (AI Visibility) همواره مستلزم درک عمیق ساختار اطلاعات، نحوه بازیابی، اعتبارسنجی و حافظه عامل‌های هوشمند است.

هوش جلسات نیز دقیقاً با همین چالش‌های بنیادین معماری اطلاعات مواجه است:
- *چه کسی چه مطلبی را بیان کرد؟*
- *چه تصمیمات قطعی اتخاذ شد؟*
- *کدام نقل‌قول یا سند از هر ادعا پشتیبانی می‌کند؟*
- *این گفتگو چگونه به تصمیمات جلسات قبلی متصل می‌شود؟*
- *کدام اطلاعات معتبر و مستند هستند و کدام حدس و گمانند؟*

این پروژه در جریان تحقیقات پیرامون سیستم‌های هوشمند اطلاعاتی و حافظه پایدار عامل‌ها شکل گرفت. وقتی یک جزء بازاستفاده‌پذیر مسئله‌ای واقعی را حل می‌کند، ترجیح می‌دهم آن را مستند کرده و منتشر کنم تا دیگران نیازی به صرف مجدد وقت برای حل آن نداشته باشند.

## قابلیت‌های کلیدی

- **استخراج ساختاریافته هوش جلسات**: تبدیل متن گفتگوها به اشیاء منسجم `MeetingRecord` شامل تصمیمات، اقدامات، اختلافات و نقل‌قول‌های مستند.
- **حافظه ماندگار میان‌جلسه‌ای**: ذخیره‌سازی در پایگاه داده محلی SQLite بدون نیاز به سرویس‌های پس‌زمینه سنگین، همراه با جداول رابطه‌ای برای بازیابی دقیق تصمیمات قبلی بدون پر کردن بی‌مورد پنجره زمینه (Context Window) مدل.
- **گراف ارتباطی و تبارشناسی جلسات**: ثبت ارتباطات معنادار میان جلسات مختلف (`ادامه‌دهنده`، `جایگزین‌کننده`، `ارجاع‌دهنده`، `مسدودکننده`).
- **اصلاحات مدیر با حفظ اصالت داده (Audit Provenance)**: امکان اصلاح خطاهای استخراج توسط مدیر جلسه همراه با ثبت کامل سوابق و دلایل اصلاح.
- **معماری ماژولار مستقل از ارائه‌دهنده**: پشتیبانی از OpenAI، Groq، Deepgram و Faster-Whisper محلی با قابلیت اجرای آزمایشی کاملاً آفلاین بدون هزینه.

---

## مهارت‌ها، ابزارها، ارائه‌دهندگان و مدل‌ها

تفکیک معماری در این مخزن:

- **مهارت (Skill)**: دستورالعمل‌ها و منطق فرایندی که هرمس می‌آموزد (در پوشه `skills/`).
- **ابزار / پلاگین (Tool / Plugin)**: کدهای اجرایی پایتون که در محیط هرمس ثبت می‌شوند.
- **مدل (Model)**: مدل هوش مصنوعی زیربنایی (مانند `whisper-large-v3` یا `gpt-4o`).
- **ارائه‌دهنده (Provider)**: زیرساخت اجرای مدل (مانند Groq، OpenAI یا پردازنده محلی).

## نصب و راه‌اندازی

### ۱. نصب به عنوان پلاگین هرمس

```bash
hermes plugins install tmolavi/hermes-meeting-intelligence
```

### ۲. نصب به عنوان بسته مستقل پایتون

```bash
# بسته پایه (پردازنده محور)
pip install hermes-meeting-intelligence

pip install "hermes-meeting-intelligence[local-stt]"
```

## استفاده سریع (Quick Start)

```python
import asyncio
from hermes_meeting_intelligence import MeetingPipeline, MeetingMemoryStore


async def main():
    pipeline = MeetingPipeline()
    transcript = """
    [علی]: تصمیم گرفتیم از SQLite برای حافظه بلندمدت جلسات استفاده کنیم.
    [رضا]: موافقم. پیاده‌سازی اسکیمای داده و تست‌ها تا پنج‌شنبه بر عهده من خواهد بود.
    """
    record = await pipeline.process_transcript(transcript, title="جلسه معماری داده", language="fa")
    store = MeetingMemoryStore("~/.hermes/meeting_memory.sqlite")
    meeting_id = store.save_meeting(record)
    print(f"جلسه با شناسه {meeting_id} و {len(record.decisions)} تصمیم ذخیره شد.")


if __name__ == "__main__":
    asyncio.run(main())
```
